
A collection of various 32x32 tileset templates, included as an aseprite file and pngs. Includes Wang, Blob, and gms2 tilesets, edited for ease of use!

Edits include having only one colour per terrain, marking duplicate tiles, and making "connected" versions that I find make mistakes more obvious when checking if autotile/terrain rules were properly set up. See connected.png for a side by side comparison.

Huge shout out to all the lovely people who figured out and then shared the math and layouts! You are some of my favourite people on the internet, and have fueled a two year hyperfixation.

Notes

    - I have taken the liberty of nicknaming some of the blob arrangements for easier reference and funsies. If anyone comes up with better names please let me know!
    - For the Wang tiles, I am using Boris the Brave's naming scheme, which can be found here. https://www.boristhebrave.com/2021/11/14/classification-of-tilesets/
    - The game maker studio templates' first tile is crossed out. This is normal and intentional, as gms2 will not allow you to use that cell's tile for autotiles. Tiles are also in order for easy autotile settup.
    - The colour #dfe6e0 (very light teal, looks white), does not represent a terrain and can be removed/ignored without issues
    - "Connected" layouts have the same layout as their non-connected counterpart.
    - In connected layouts, red losanges are placed where two different colours would overlap.
    - Suggestions and edits are more than welcome! You can comment here https://opengameart.org/content/tileset-templates
