This is a set of Wang tiles with 5 variations for each slot. In a side folder, incomplete squares (with transparent sides) are included for extra permutation fun.
The tiles were made grayscale for full colorblindness accessibility.

Read more about Wang tiles here: https://en.wikipedia.org/wiki/Wang_tile

This was created as testing for a tool I'm building in Godot to manage, combine and export 2D modular assets.
The script is open-source and can be accessed here: https://codeberg.org/croomfolk/ModularAssetManager

I released these Wang tiles into the public domain (Creative Commons Zero). They cannot be copyrighted in any juristiction I know of, as they fall under the Threshold of Originality criteria.

I hope this is useful to you!
